# @nagarsathi/frontend

Voice-first, multilingual (`mr-IN`, `hi-IN`, `en-IN`) React frontend for NagarSathi (CITY-02).

## Purpose
- Provides the citizen voice interface (mic-first workflow for low-literacy & elderly citizens like Ramabai).
- Handles consent capture, document verification UI, draft form inspection (`FORM_FILLED`), explicit submission approval gate (`approval.given === true`), live status tracking, stall escalation view, and simulated office call transcript UI.
- Displays masked PII only (last 4 digits) and includes the mandatory prototype footer (`"Prototype. Mock portal. Demo data only."`).
